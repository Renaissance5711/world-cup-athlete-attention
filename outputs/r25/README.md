# R25 full-ranking audit outputs

Versioned compact outputs:

- `rank_reversal_summary.json`: primary counts, rates, intervals and interpretation boundaries.
- `rank_reversal_decomposition_table.csv`: compact table source for the submission.
- `rank_reversal_athlete_displacements.csv`: athlete-level rank displacement audit.
- `SHA256SUMS_R25.txt`: checksums for the new code, tests, documentation and compact outputs.

The complete pair-level table and 10,000 draw-level bootstrap table are generated by `code/run_rank_reversal_decomposition.py` and are intentionally not versioned because they are deterministic derivatives of the frozen inputs and fixed seed.
