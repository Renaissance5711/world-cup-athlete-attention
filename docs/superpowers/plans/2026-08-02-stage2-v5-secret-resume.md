# Stage 2 V5 Secret Resume Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resume the Stage 2 V5 pipeline from the saved OpenAlex cache without relying on the temporary Google Drive payload, while loading the API key only from GitHub Actions Secrets and accurately propagating analysis failure to the workflow conclusion.

**Architecture:** Reconstruct the code and V3 input archives from the existing `tem_stage2_v5_payload/**/part_*.b64` files checked into the run branch. Inject `OPENALEX_API_KEY` from the repository secret, restore the existing cache by prefix, run the unchanged analysis, upload diagnostics unconditionally, and add a final exit-code gate after artifact upload.

**Tech Stack:** GitHub Actions YAML, Bash, Python 3.11, pytest, actions/cache, actions/upload-artifact.

## Global Constraints

- Never print, persist, upload, cache, or commit the OpenAlex API key.
- Reuse the existing OpenAlex cache prefix `tem-stage2-v5-openalex-`.
- Preserve the V3 input assertions for 1,881 projects, 6,602 strict rows, and 273 authors.
- Upload diagnostics even when the analysis exits non-zero.
- The workflow conclusion must be failure whenever `stage2_v5_exit_code.txt` is missing or non-zero.
